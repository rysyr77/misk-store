# متجر مسك للعطور — واجهة أمامية

واجهة متجر عربية متجاوبة من اليمين إلى اليسار، بهوية سوداء وذهبية، مرتبطة بواجهة PHP وقاعدة MySQL.

## التشغيل

انسخ المجلد إلى `C:\xampp\htdocs\misk-store`، شغّل Apache وMySQL، ثم استورد `backend/database/misk_store.sql` من phpMyAdmin. افتح بعدها:

`http://localhost/misk-store/`

لا تفتح `index.html` مباشرة؛ يجب تشغيله عبر Apache حتى تعمل PHP وMySQL. لاختبار الاتصال افتح `backend/api/health.php`، وعدّل بيانات الاتصال في `backend/db.php` عند الحاجة.

## دخول المدير التجريبي

انقر مرتين على الشعار في الترويسة، ثم أدخل: اسم المستخدم `admin` وكلمة المرور `misk123`. المنتجات تُحفظ في MySQL وتظهر في الصفحة الرئيسية، وتم إصلاح الإضافة والتعديل والحذف ورفع الصور.

## أهم الملفات

- `index.html` — بنية أقسام المتجر، نافذة التفاصيل، الدخول ولوحة الإدارة.
- `css/` — الهوية البصرية والتنسيق المتجاوب.
- `js/` — جلب المنتجات وواجهة المتجر ولوحة الإدارة.
- `backend/database/misk_store.sql` — مخطط قاعدة البيانات وحساب المدير الأولي.
- `assets/` — صور المتجر، صورة العبوة بالشعار في `misk-hero-branded.png`، والشعار الشفاف `misk-logo.png`.

رابط واتساب في الواجهة يستخدم الرقم الظاهر في المستند والصورة المرجعية: `+963 306 993 027 531`. يمكنك تعديل `WHATSAPP_NUMBER` أعلى `app.js` إذا أردت تغيير الرقم.

## ملاحظات النطاق

قبل الرفع إلى استضافة حقيقية، غيّر كلمة مرور المدير وبيانات MySQL، ولا تستخدم root بدون كلمة مرور. يجب أن يكون مجلد `uploads` قابلاً للكتابة من PHP. زر طلب المنتج يفتح واتساب برسالة تتضمن تفاصيل المنتج والكمية والإجمالي.
